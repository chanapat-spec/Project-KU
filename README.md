# 🏐 KU Volley Quest (8-Bit Action Cam Game)

เว็บเกมแนว 8-Bit Retro RPG ผสมผสานเทคโนโลยี **Action Cam (AI Pose Detection)** สำหรับนักเรียนระดับประถมศึกษา เพื่อฝึกทักษะกีฬาวอลเลย์บอล (การอันเดอร์บอล & การเซ็ตบอล) จากที่บ้านผ่านกล้องโทรศัพท์มือถือ โดยไม่ต้องมีลูกบอลจริง พร้อมระบบสะสมแต้ม, แต่งตัวละคร, อนิเมชันตัวอย่าง, และส่งคะแนนเข้า Google Sheets อัตโนมัติ

---

## 🌟 ฟีเจอร์ที่อัปเดตใหม่ทั้งหมด (Latest Features)

1. **ครูผู้ฝึกสอนในเกม: "โค้ชซูน (Coach Soon)" 🧢**
   - NPC ประจำโรงยิมคอยให้คำแนะนำนักเรียนในการอันเดอร์และเซ็ตบอล

2. **ระบบส่งคะแนนขึ้นคลาวด์อัตโนมัติ (Google Sheets Cloud Sync) ☁️:**
   - แก้ปัญหาเด็กเล่นที่บ้านแล้วครูไม่เห็นคะแนน!
   - อาจารย์สามารถสร้าง Google Apps Script สั้นๆ 5 บรรทัด แล้วนำ Webhook URL มาวางในหน้า Admin
   - เมื่อนักเรียนเล่นจบแต่ละมิชชั่น คะแนนจะถูกส่งตรงเข้าตาราง Google Sheet ของครูทันที

3. **ตรวจวัดคุณภาพทักษะ & หลักฐานภาพถ่าย (Form Accuracy & Snapshot Evidence) 📸:**
   - **Form Accuracy (%):** ระบบคำนวณเปอร์เซ็นต์ความเป๊ะของท่าทางตลอดการเล่น พร้อมตัดเกรดเป็น **A+, A, B, C**
   - **Composite Evidence Snapshot:** ถ่ายรูปนักเรียนคู่กับโครงร่างกระดูก 8-bit สีเขียว พร้อมประทับตราผลการทดสอบ (ชื่อ, ห้อง, เลขที่, ท่า, เกรด, วันที่) สามารถกดดาวน์โหลดภาพไปส่งครูได้ทันที

4. **ระบบแต่งตัวละคร & สัตว์เลี้ยง (Wardrobe & Skins) 👕:**
   - ปลดล็อกสีเสื้อทีม: เขียว KU, แดงไฟเออร์, น้ำเงินโอเชี่ยน, ทองแชมเปี้ยน
   - ปลดล็อกไอเทม: สนับเข่าเรโทร, ผ้าคาดหัว
   - **สัตว์เลี้ยงนำโชค:** ลูกวอลเลย์บอลติดปีก 8-bit บินกระพือปีกตามตัวละครในยิม!
   - **Daily Streak (🔥):** นับจำนวนวันที่เข้ามาฝึกซ้อมติดต่อกัน

5. **ภาพอนิเมชันสาธิตท่าทาง 8-bit (Visual Ghost Tutorial) 👀:**
   - ในหน้าภารกิจก่อนเปิดกล้อง มีภาพอนิเมชัน 8-bit ขยับสาธิตท่าทางให้ดูชัดเจน (อันเดอร์บอลย่อ-ยืดแขนตึง / เซ็ตบอลยกมือรูปถ้วย)

6. **ระบบจัดการห้องเรียน (Room Manager) 🏫:**
   - ค่าเริ่มต้นมี **ห้อง 1 ถึง ห้อง 20** ให้เลือก
   - ครูสามารถกดปุ่มขยายเป็นห้อง 50, 99 หรือพิมพ์ชื่อห้องเฉพาะของโรงเรียนได้เอง

## 🚀 วิธีเปิดใช้งาน (How to Run)

### 1. เปิดเซิร์ฟเวอร์บนเครื่อง Mac
เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วรันคำสั่ง:
```bash
./start.sh
```
*(หรือรัน `ruby server.rb`)*

ระบบจะเปิด HTTPS Server พอร์ต `8443` ขึ้นมาโดยอัตโนมัติ

---

### 2. วิธีเข้าเล่นบนโทรศัพท์มือถือ (สำคัญมาก!) 📱
1. นำโทรศัพท์มือถือเชื่อมต่อ **Wi-Fi เดียวกับเครื่องคอมพิวเตอร์**
2. เปิดเบราว์เซอร์ Safari หรือ Chrome บนมือถือ แล้วพิมพ์ที่อยู่ IP:
   ```
   https://192.168.1.170:8443
   ```
3. **การกดยืนยันใบรับรองความปลอดภัย (ครั้งแรกเท่านั้น):**
   - **บน iPhone (Safari):** กด *"Show Details"* ➔ กด *"visit this website"*
   - **บน Android (Chrome):** กด *"Advanced"* ➔ กด *"Proceed to 192.168.x.x (unsafe)"*
4. กดยินยอม (Allow) ให้เข้าถึงกล้อง วางโทรศัพท์พิงไว้ แล้วถอยห่างออกมาเล่นได้เลย!
