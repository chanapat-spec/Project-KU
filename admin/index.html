⚪ กำลังตรวจสอบสถานะ...

ซิงค์คะแนนนักเรียนแบบเรียลไทม์ และเก็บรูปถ่ายหลักฐานการทำท่าทางลง Cloud Storage อัตโนมัติ

🛠️ ขั้นตอนการเชื่อมต่อ Supabase:

  1. เข้าเว็บ supabase.com ล็อกอินเข้าบัญชี และเปิดโปรเจกต์ของคุณ
  2. ไปที่เมนู Project Settings (รูปฟันเฟือง) ➔ API
  3. คัดลอก Project URL และ anon / public API key มาวางในช่องด้านบนนี้แล้วกด "บันทึกการเชื่อมต่อ"
  4. ไปที่เมนู SQL Editor ในแดชบอร์ด Supabase
  5. เปิดไฟล์ supabase_schema.sql (ในโฟลเดอร์โปรเจกต์นี้) คัดลอกโค้ดทั้งหมดไปวางแล้วกด Run
  6. สคริปต์จะสร้างตาราง students, scores, เปิด Realtime และสร้าง Storage Bucket homework-snapshots ให้ทันที!

☁️ ตัวเลือกเสริม: Google Sheets Webhook (ส่งคะแนนสำรองเข้าชีต)

📝 ขั้นตอนติดตั้ง Google Apps Script:

  1. สร้าง Google Sheets ใหม่ขึ้นมา 1 แผ่น
  2. ไปที่เมนู ส่วนขยาย ➔ Apps Script
  3. วางโค้ด: 
    function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var d = JSON.parse(e.postData.contents);
  sheet.appendRow([d.timestamp, d.room, d.studentNumber, d.studentName, d.exerciseId, d.reps, d.targetReps, d.accuracy, d.grade, d.xpEarned]);
  return ContentService.createTextOutput("OK");
}
  4. กด Deploy ➔ New deployment เลือก Web App, Who has access = Anyone แล้วนำ URL มาวาง
